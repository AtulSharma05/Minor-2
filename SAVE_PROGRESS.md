# Save Progress Checklist

1. Review current changes:
   - git status

2. Stage project2 only:
   - git add project2

3. Commit with a message:
   - git commit -m "Add NutriPal full-stack project with Mongo Express Node backend"

4. Push to your branch:
   - git push

If this is a brand-new repository, run first:
- git init
- git branch -M main
- git remote add origin <your-repo-url>
